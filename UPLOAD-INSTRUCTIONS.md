# Upload to GitHub — no command line required

1. Sign in at https://github.com and select **New repository**.
2. Name it `operation-echoleak-threat-hunt`, choose **Public** only after reviewing the data, and initialize with a README if you prefer.
3. Open the repository, choose **Add file → Upload files**, and drag the *contents* of this extracted project folder into the upload area. GitHub's browser upload supports folder drag-and-drop in supported browsers.
4. If GitHub does not preserve folders, create the folders in GitHub first and upload their files separately.
5. Commit with a message like `Add Operation ECHOLEAK investigation portfolio`.
6. Open README.md to check that the links to the case study and KQL folder work.
7. Pin the repository on your GitHub profile when you are happy with it.

**Before making public:** confirm the scenario is a permitted lab exercise, check all identifiers, and review the README's evidence limitations. If uncertain, start with a **Private** repository and change visibility after review.
